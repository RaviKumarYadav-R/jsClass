A structured **Beginner → Advanced → Professional** JavaScript curriculum for learning, revision, teaching, practice, and projects.

## Core Topics Added

- Scope, lexical scope, scope chain
- Hoisting, TDZ, execution contexts
- `this`, `call`, `apply`, `bind`
- Closures and higher-order functions
- Prototypes and prototype chains
- Promises, async/await, event loop
- ES modules and CommonJS concepts
- Error handling and custom errors
- Map, Set, WeakMap, WeakSet
- Iterators and generators
- Symbols and BigInt
- Proxy, Reflect, property descriptors
- DOM events, bubbling, capturing, delegation
- Fetch, HTTP, AbortController
- Storage and browser APIs
- Composition, dependency injection, SOLID
- DSA and algorithmic thinking
- Testing and TypeScript
- Design patterns and application architecture

## Recommended Order

Do not try to finish every file in one pass.

1. Learn the concept.
2. Run the examples.
3. Rewrite the example without looking.
4. Solve the practice questions.
5. Build the related mini-project.
6. Explain the topic to someone else.

## Note Style

The new chapters use compact `//*` teaching notes, runnable JavaScript examples, mental models, common mistakes, and practical use cases.

## Existing OOP Files

The existing OOP chapters remain available. In particular, `Oops_Javascript/06_inheritence.js` contains the original prototype-based inheritance example. The new inheritance material should be studied with modern `class`, `extends`, and `super` syntax first, followed by the prototype-chain explanation.

## Goal

This repository is intended to take you from writing your first JavaScript statement to understanding the language deeply enough to build frontend applications, backend applications, browser tools, and full-stack projects without depending on tutorials.
