# Teaching System

This folder defines how to use the repository as a teaching course.

## One chapter = one lesson

For each topic, teach in this sequence:

### 1. Definition
State exactly what the concept is.

### 2. Problem
Explain what problem the feature solves.

### 3. Syntax
Show the smallest valid syntax.

### 4. Mental model
Draw the values, references, call stack, prototype chain, or event flow when relevant.

### 5. Example
Start with a tiny example.

### 6. Real use
Show where a developer actually uses the concept.

### 7. Mistakes
Show the most common incorrect patterns and why they fail.

### 8. Practice
Use output prediction, debugging, implementation and refactoring questions.

### 9. Recap
End with 3–5 rules the learner must remember.

## Teacher checklist

- [ ] Can the learner define it without memorizing a sentence?
- [ ] Can the learner write the basic syntax from memory?
- [ ] Can the learner predict the output?
- [ ] Can the learner explain why the output happens?
- [ ] Can the learner identify a common mistake?
- [ ] Can the learner use it in a small project?
- [ ] Can the learner explain it back to someone else?

## Practice levels

**L1 — Recall:** definitions and syntax.

**L2 — Understand:** predict output and explain execution.

**L3 — Apply:** write a solution from requirements.

**L4 — Debug:** find and fix incorrect code.

**L5 — Design:** choose an appropriate feature and explain trade-offs.

**L6 — Teach:** explain the topic without looking at notes.
