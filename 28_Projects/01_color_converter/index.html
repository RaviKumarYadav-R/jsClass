📚 HSL Color System

HSL stands for Hue, Saturation, and Lightness. It is a color model that makes it easier to understand and adjust colors.

  • Hue: Defines the color using values from 0° to 360°.
  • Saturation: Controls the intensity of the color from 0% to 100%.
  • Lightness: Controls how light or dark the color appears.
  • Syntax: hsl(hue, saturation%, lightness%)
  • Example: hsl(220, 80%, 50%) creates a vivid blue.
