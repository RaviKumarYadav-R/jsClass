# JavaScript Design Patterns

Study patterns as solutions to recurring design problems, not as rules to apply everywhere.

## Creational
- Factory
- Abstract Factory
- Builder
- Singleton (use carefully)

## Structural
- Adapter
- Decorator
- Facade
- Proxy
- Composite

## Behavioral
- Strategy
- Observer
- Command
- State
- Template Method
- Iterator
- Chain of Responsibility

## JavaScript-Native Patterns
- Module pattern
- Factory functions
- Closures for encapsulated state
- Composition
- Higher-order functions

## Learning Method

For each pattern document:

1. Problem
2. Naive solution
3. Pattern structure
4. JavaScript implementation
5. Trade-offs
6. When not to use it
7. Real project example
